# SNOW ROUTE

Snow Manの作品やイベントを、「あと何日」と節目の積み重ねで楽しむためのファンメイドツールです。

## ファイル

- `index.html`：画面の骨組み
- `style.css`：デザイン
- `script.js`：動作とデータ保存
- `chart-periods.json`：Billboard・オリコン集計期間
- `calendar.json`：誕生日・結成日・デビュー日

## GitHub Pages

リポジトリ直下に上記5ファイルを置き、GitHub Pagesを有効にしてください。

登録内容は利用者のブラウザ内（localStorage）に保存されます。ブラウザデータを削除すると失われる可能性があるため、設定画面のバックアップ機能を利用してください。

## 注意

非公式のファンメイドツールです。Snow Man、所属事務所、各チャート運営会社とは関係ありません。
